# 🎵 Spotify Clone

This is a **Spotify Clone** that I created as a front-end development project.

The project is inspired by the design and layout of Spotify and was built to practice my **HTML and CSS** skills.

## 🛠️ Technologies Used

* HTML
* CSS

## ✨ Features

* Spotify-inspired user interface
* Navigation sidebar
* Music playlist section
* Recently played section
* Music player interface
* Responsive layout

## 📂 Project Structure

```text
Spotify-Clone/
│
├── index.html
├── style.css
├── assets/
└── README.md
```
